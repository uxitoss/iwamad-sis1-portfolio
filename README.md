# Veronika Starkova - Portfolio

Live site: https://uxitoss.github.io/iwamad-sis1-portfolio/

## About

This is my portfolio site made with HTML, CSS and JavaScript. I made it for my teacher and classmates so they can see my work from the IWaMAD course. It has an About me section, project cards with GitHub links and a contact form.

## Design decisions

1. **Dark theme by default.** I like dark pages more, and they are easier on the eyes at night. I also added a Light/Dark button, and the choice is saved after reload.

2. **CSS variables.** I keep all colors, font sizes and spacing in `:root`. This way everything looks the same, and for the light theme I only change a few colors.

3. **Cards in one column on phones.** On a small screen the cards go one under another because it is easier to read. From 768px they stand in three columns.
